# wdd130-jensen

Coursework and projects for **BYU-Idaho WDD 130 — Web Fundamentals**, by Jeff Jensen.

## 🌐 Live Site
**https://github.barefootbetters.com/wdd130-jensen/**

Published with GitHub Pages from the `main` branch (root). The homepage is the personal **portal** that links to every project below.

## What's Inside
| Folder / File | Description |
|---|---|
| `index.html` | Portal home — featured projects, skills table, contact form |
| `ice.html` | Index of all In-Class Exercise (ICE) challenges |
| `about.html` | About Me page |
| `site-plan.html` | Design document — wireframe, color scheme, fonts, logo |
| `ice/` | Individual ICE challenges (favorite devotionals, Father's Day, gallery, sign-up form, prophet card, apostle spotlight) |
| `wwr/` | Whitewater Rafting multi-page site (Week 4) |
| `assignments/` | Weekly assignment work |
| `teamproject/` | Client / Developer team-project staging (starter files + progress report) |
| `styles/` | Shared stylesheet for the portal |
| `images/` | Logo, profile photo, and wireframe |

## Tech
Hand-written HTML5 and CSS3 (Flexbox + Grid), Google Fonts (Montserrat + Open Sans), hosted on GitHub Pages.
